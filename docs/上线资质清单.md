## 📝 AppGallery Connect 填写指南

### 第一步：创建应用
1. 登录 developer.huawei.com
2. 进入 AppGallery Connect
3. 点击「新建应用」
4. 选择平台：Android / HarmonyOS
5. 选择类型：APK / HAP

### 第二步：填写基础信息
```
应用名称：鸿蒙Markdown编辑器
应用分类：工具 → 笔记/文档
支持设备：手机/平板
支持系统：HarmonyOS 5.0+
```

### 第三步：上传安装包
- 上传已签名的 .hap 文件

### 第四步：完善应用信息
- 上传图标 (1024x1024)
- 上传截图 (5张)
- 填写应用描述
- 填写隐私政策链接

### 第五步：提交审核
- 确认所有信息无误
- 提交审核
