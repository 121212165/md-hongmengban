# 图标与截图设计规范

## 📱 应用图标规范

### 尺寸要求

| 用途 | 尺寸 | 格式 | 说明 |
|------|------|------|------|
| 应用市场 | 1024 x 1024 | PNG | 主图标 |
| 华为应用市场 | 216 x 216 | PNG | 短橱窗图 |
| 应用详情页 | 480 x 800 | PNG | 详情大图 |
| 热搜词 | 240 x 240 | PNG | 热搜图 |

### 设计建议

```
┌─────────────────────────┐
│                         │
│      📝                 │
│    Markdown             │
│                         │
│   ┌─────────────────┐   │
│   │  # Hello World │   │
│   └─────────────────┘   │
│                         │
│  鸿蒙Markdown编辑器     │
└─────────────────────────┘

设计元素：
- 文档图标 📄 或 ✏️
- M 或 MD 字样
- 鸿蒙品牌色：#007AFF
```

### 颜色方案

```
主色调：#007AFF (鸿蒙蓝)
背景色：#FFFFFF (白) / #1D1D1F (暗)
强调色：#34C759 (成功绿)
```

## 📸 截图规范

### 必需截图（5张）

| # | 截图内容 | 尺寸建议 | 说明 |
|---|----------|----------|------|
| 1 | 主界面-编辑状态 | 1080x1920 | 展示双栏布局，编辑内容 |
| 2 | 工具栏使用 | 1080x1920 | 展示快捷工具栏按钮 |
| 3 | 文件列表 | 1080x1920 | 展示侧边栏文件管理 |
| 4 | 暗色主题 | 1080x1920 | 展示暗黑模式效果 |
| 5 | 预览效果 | 1080x1920 | 展示Markdown渲染效果 |

### 截图命名

```
screenshot_1.png  - 主界面
screenshot_2.png  - 工具栏
screenshot_3.png  - 文件列表
screenshot_4.png  - 暗色主题
screenshot_5.png  - 预览效果
```

## 🎬 设计工具推荐

- **Canva** (在线设计)
- **Figma** (专业设计)
- **Photoshop**
- **Affinity Designer**

---

## 📋 快速生成提示

1. 在手机/模拟器上截图
2. 使用`截图宝`类工具添加文字
3. 确保分辨率清晰

---

## ❌ 避免事项

- ❌ 使用其他应用商店logo
- ❌ 包含敏感内容
- ❌ 模糊或拉伸变形
- ❌ 包含个人联系方式
