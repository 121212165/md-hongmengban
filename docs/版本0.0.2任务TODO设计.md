# hongmengMD 版本 0.0.2 任务 TODO 设计

## 1. 文档目的

- 把 `0.0.2` 技术路线拆成可执行任务。
- 为开发、联调、验收提供统一清单。
- 让任务按优先级和依赖顺序推进，而不是并行扩散。

## 2. 使用方式

- `P0` 为版本阻塞项，必须完成。
- `P1` 为强建议项，在 `0.0.2` 内尽量完成。
- 每个任务包含：
  - 目标
  - 主要工作
  - 完成标准

## 3. P0 任务

## T001 页面结构重构

目标：

- 将当前单页工作台拆为三页结构。

主要工作：

- 新建工作区页
- 新建编辑页
- 新建预览 / 导出页
- 重构页面导航入口
- 从主页面移除接力记录、导出记录、同屏预览等混排结构

完成标准：

- 浏览、编辑、预览不再堆在同一页面
- 用户能从工作区页进入编辑页和预览页

关联模块：

- `entry/src/main/ets/pages/main/EditorPage.ets`
- 新页面目录与入口路由

## T002 工作区页落地

目标：

- 把工作区和文档管理从当前主页面里独立出来。

主要工作：

- 工作区列表展示
- 当前工作区高亮
- 文档列表展示
- 新建文档入口
- 基础模板入口
- 导入文件入口

完成标准：

- 用户可以清晰切换工作区
- 用户可以从工作区页进入指定文档

关联模块：

- `ProjectService`
- `FileService`
- 工作区页组件

## T003 编辑页落地

目标：

- 建立专注输入的编辑场景。

主要工作：

- 标题编辑
- 正文编辑
- 自动保存状态展示
- 高频 Markdown 快捷操作
- 返回工作区和进入预览页入口

完成标准：

- 编辑页不再展示资产流卡片和历史信息
- 内容修改可自动保存

关联模块：

- `EditorComponents`
- `FileService`

## T004 输入法与快捷键避让

目标：

- 解决高频快捷键被软键盘遮挡的问题。

主要工作：

- 重做快捷操作条布局
- 仅保留高频语法插入
- 让快捷操作围绕编辑器布局，而不是固定页面底部大工具栏

完成标准：

- 软键盘弹起时快捷操作仍可用
- 快捷操作不再占据大面积底部空间

建议保留的高频项：

- 标题
- 列表
- 待办
- 引用
- 加粗
- 行内代码

## T005 预览 / 导出页落地

目标：

- 建立独立的内容确认和输出页面。

主要工作：

- 渲染预览
- 导出格式选择
- 导出按钮
- 分享按钮
- 导出结果反馈

完成标准：

- 用户可以在独立页面查看渲染结果
- 导出和分享不再从混杂页面中触发

## T006 真实导出能力

目标：

- 替换当前占位式导出实现。

主要工作：

- 重新定义导出路径策略
- 输出真实可用文件
- 至少优先完成 Markdown / Text 的稳定导出
- 明确 PDF / 长图 / 分享卡片在 `0.0.2` 的实现范围

完成标准：

- 导出文件可被用户实际访问
- 导出结果与文件格式一致，不再是伪装文本

风险说明：

- `PDF` 与长图可能需要降级为后置实现
- `0.0.2` 不要求一次性完成所有复杂格式

## T007 系统分享接入

目标：

- 从导出结果直接进入系统分享能力。

主要工作：

- 基于导出结果准备分享文件
- 调用系统分享接口
- 补充失败反馈

完成标准：

- 用户可以从应用内把导出内容分享到外部

## T008 文件导入能力

目标：

- 让应用具备“接收已有内容”的能力。

主要工作：

- 接入本地文件选择
- 支持 Markdown / Text 导入
- 导入后生成文档并归属工作区
- 导入失败反馈

完成标准：

- 用户可以选择本地文件导入到当前工作区

## T009 文件可见性与管理

目标：

- 让用户知道导出的文件在哪里。

主要工作：

- 统一导出目录策略
- 展示导出结果位置或结果提示
- 明确“最近导出”最小可用反馈方式

完成标准：

- 用户不会再出现“保存成功但文件找不到”的情况

## T010 主流程清理

目标：

- 清理与 `0.0.2` 边界不一致的入口和文案。

主要工作：

- 下线接力相关主入口
- 下线多设备相关卖点文案
- 弱化模板卖点
- 调整首页文案与产品定位一致

完成标准：

- 页面上不再高显性展示本版本不做的能力

## 4. P1 任务

## T011 `FileService` 职责收敛

目标：

- 让本地数据中枢继续可维护。

主要工作：

- 梳理文档、工作区、导出、导入相关职责
- 降低与接力能力的耦合
- 补充必要的工具方法与错误处理

完成标准：

- `FileService` 能支撑三页式结构而不继续恶化

## T012 工作区与文档管理细节

目标：

- 让资产管理操作更稳定。

主要工作：

- 当前文档切换一致性
- 当前工作区切换一致性
- 新建文档后的选中策略
- 删除或空状态处理

完成标准：

- 工作区和文档切换逻辑明确且真机表现稳定

## T013 预览表现优化

目标：

- 提升预览页可信度。

主要工作：

- 优化 Markdown 块级显示
- 提升标题、列表、引用、代码块的可读性
- 处理空状态

完成标准：

- 预览与编辑结果对应关系更清晰

## T014 真机回归清单更新

目标：

- 让 `0.0.2` 每轮迭代都有统一回归口径。

主要工作：

- 更新真机测试项
- 明确导入、导出、分享、工作区切换、自动保存验证路径

完成标准：

- 测试清单可直接用于每轮回归

## 5. 不进入 0.0.2 的任务

以下任务不应被拉入当前版本：

- 多设备同步
- 多设备接力
- 系统搜索
- 系统备忘录同步
- Agent 能力
- 模板增强系统

处理原则：

- 不立项
- 不做半成品入口
- 不在主页面保留卖点文案

## 6. 推荐执行顺序

### 第一批

- T001 页面结构重构
- T002 工作区页落地
- T003 编辑页落地
- T004 输入法与快捷键避让
- T005 预览 / 导出页落地

### 第二批

- T006 真实导出能力
- T007 系统分享接入
- T008 文件导入能力
- T009 文件可见性与管理

### 第三批

- T010 主流程清理
- T011 `FileService` 职责收敛
- T012 工作区与文档管理细节
- T013 预览表现优化
- T014 真机回归清单更新

## 7. 里程碑定义

## M1 结构完成

判定：

- 三页结构完成
- 单页堆叠式主页面退出主流程

## M2 闭环完成

判定：

- 导入、编辑、预览、导出、分享主链路打通

## M3 版本收口

判定：

- 真机回归通过
- 页面文案和实际能力一致
- `0.0.2` 不做的能力已从主流程退出

## 8. 一句话总结

`0.0.2` 的 TODO 设计应围绕“页面重构 + 本地内容闭环 + 文件可见与可分享”展开，其它方向全部延后。
